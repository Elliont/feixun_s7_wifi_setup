# 斐讯 S7/S7p 配网工具

本工具用于将斐讯 **S7 / S7P** 体脂秤的连接目标，从厂商云服务改为用户自建的服务器。
整个过程通过一部安卓手机完成，无需拆机或改动硬件。

> **支持范围：仅 S7 / S7P**
>
> 斐讯原厂 App 对这三款机型用的是三套互不相通的配网方式，按机型硬分流：
>
> | 机型 | 原厂配网方式 |
> | --- | --- |
> | S7 / S7P | Espressif Esptouch（UDP 广播 Wi-Fi 凭据） |
> | S7PE | FlyLink（UDP 28888） |
> | S9 | 蓝牙 GATT 命令 |
>
> 本项目实现的是 Esptouch 那条，因此 **S7PE 与 S9 暂不支持**。
> 如果配网日志里出现 `S7PE` / `S9`，说明机型已被识别，但流程仍按 S7 执行，通常会卡在「等待握手包」。

## 准备工作

开始前请确认以下条件：

| 项目 | 要求 |
| --- | --- |
| 安卓手机 | 连接至 2.4GHz Wi-Fi（不支持 5GHz）；关闭 VPN 与网络代理 |
| 服务器 | 已部署 [feixun_s7_web](https://github.com/Elliont/feixun_s7_web) 服务端，并记下其**局域网 IP**（如 `192.168.1.10`） |
| 体脂秤 | 长按机身 RESET 键，直至屏幕上的 `@` 符号闪烁，表示已进入配网模式 |

## 操作步骤

1. **下载安装**：前往 [Releases](https://github.com/Elliont/feixun_s7_wifi_setup/releases) 下载 `app-release.apk` 并安装到手机。
2. **填写参数**：打开应用，Wi-Fi 名称与端口会自动填好，你只需填写：
   - Wi-Fi 密码
   - 服务器的局域网 IP（请勿填写公网 IP）
3. **开始配网**：点击「开始配置」并等待完成。整个过程约 1～2 分钟，期间请保持应用在前台、屏幕不要熄灭。
4. **验证结果**：配网成功后在秤上称重一次，登录服务端网页确认数据已上报。

## 常见问题

**一直停留在「等待握手包」**
- 确认手机连的是 2.4GHz 网络，VPN / 代理已关闭
- 确认秤的 `@` 正在闪烁；如未闪烁，重新长按 RESET

**握手成功但秤未连接服务器**
- 检查服务器 IP 是否为局域网地址
- 确认服务端 `30101` 端口未被防火墙拦截

**Wi-Fi 名称显示 `<unknown ssid>`**
- 确认手机定位开关已开启，并已授予应用定位权限

**提示缺少权限**
- 请允许应用申请的全部权限，否则无法读取 Wi-Fi 信息
